추억의 오락실 개인정보처리방침

최종 수정일: 2026년 9월 9일 · Privacy Policy (English summary below)

추억의 오락실은 계정이 없고 개인정보를 수집하지 않습니다. 게임 일곱 대는 전부 앱 안에 내장돼 있고, 점수·코인·설정은 이 기기에만 저장됩니다. 앱이 하는 유일한 네트워크 요청은 도전 스테이지 목록 파일을 내려받는 것 하나이며, 그때도 앱이 보내는 개인정보는 없습니다.

1. 수집하는 개인정보

없습니다. 계정·이메일·전화번호·광고 식별자·위치·연락처 어느 것도 수집하거나 전송하지 않습니다. 이 버전에는 광고 SDK와 분석 도구가 들어 있지 않습니다 — 앱 설치 파일 자체에 해당 라이브러리가 없습니다. 하이스코어에 남기는 이니셜 세 글자는 사용자가 직접 입력하는 것이고 이 기기를 벗어나지 않습니다.

2. 기기에 저장되는 것

항목저장 위치삭제 시점
하이스코어·이니셜앱 전용 저장 공간앱 삭제 시 (앱 안에서 직접 삭제도 가능)
코인 보유량·충전 시각앱 전용 저장 공간앱 삭제 시
오늘의 도전·도장판(업적) 진행앱 전용 저장 공간앱 삭제 시

앱을 삭제하면 위 데이터가 모두 함께 삭제됩니다. 서버에 사본이 남지 않습니다.

3. 네트워크 요청 — 도전 스테이지 내려받기

앱은 도전 스테이지 목록을 https://inphilchoi.github.io/arcade/ 에서 내려받습니다. 이 요청은 6시간에 한 번만 확인하며, 다음 사항이 적용됩니다.

  • 보내는 것: 없습니다. 앱은 파일을 요청하기만 하고 사용자 정보를 함께 보내지 않습니다. 로그인도 식별자도 없습니다.
  • 받는 것: 데이터뿐입니다 — 어느 게임을, 어떤 설정으로, 어디까지 하면 되는지 적힌 목록입니다. 실행되는 코드는 내려받지 않습니다. 게임 일곱 대는 모두 앱에 내장돼 있습니다.
  • 호스팅: 이 파일은 GitHub Pages 에서 제공됩니다. 모든 웹 요청과 마찬가지로 GitHub 서버에는 접속한 IP 주소 등 표준 접속 기록이 남을 수 있으며, 이는 GitHub 의 개인정보 보호정책을 따릅니다. 개발자는 그 기록을 열람하거나 보관하지 않습니다.
  • 실패해도 됩니다: 네트워크가 없으면 이전에 받아 둔 목록을 그대로 쓰고, 게임은 전부 정상 동작합니다.

4. 권한

요청하는 권한이 없습니다. 카메라·사진·위치·마이크·연락처·알림 어느 것에도 접근하지 않습니다.

5. 제3자 제공·분석·광고·결제

없습니다. 이 버전에는 광고와 인앱 결제, 구독이 모두 없습니다. 향후 버전에서 광고나 선택적 인앱 구매를 도입하게 되면, 도입 전에 이 문서를 갱신하고 앱 스토어의 개인정보 라벨을 함께 변경합니다.

6. 게임 저작권

이 앱에 실린 게임은 전부 자체 제작한 오리지널 게임입니다. 상용 게임의 ROM·데이터를 포함하지도, 내려받지도, 실행하지도 않습니다.

7. 아동의 개인정보

수집하는 정보가 없으므로 아동의 개인정보 또한 수집하지 않습니다.

Privacy Policy (English)

Retro Arcade does not collect any personal data. All seven games are built into the app; scores, coins and settings stay on your device. There is no account, no analytics, no ads and no purchases in this version.

  • Data collected: none.
  • Permissions: none requested — no camera, photos, location, microphone or contacts.
  • On-device storage: high scores, coins, daily-challenge and achievement progress, settings, and a cached challenge list. All removed when you uninstall the app.
  • Network: one request, checked at most every 6 hours, to https://inphilchoi.github.io/arcade/ to fetch the challenge-stage list. The app sends no user information with it. Only data is downloaded — never executable code. Standard web access logs may be kept by GitHub Pages under GitHub's privacy statement; the developer does not access or retain them.
  • Third parties: none.
  • Game content: every game is original work. No commercial ROMs are bundled, downloaded or run.
