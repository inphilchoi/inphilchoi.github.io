DailyMap 개인정보처리방침

최종 수정일: 2026년 9월 29일 (앱 1.1.0 기준) · Privacy Policy (English summary below)

요약 — DailyMap은 계정이 없고, 자체 서버가 없습니다. 개발자는 좌표를 받는 서버(중계·캐시 서버 포함)를 운영하지 않습니다. 즐겨찾기·최근 검색어·설정·러닝 기록은 이 앱을 설치한 기기 안에만 저장되며, 개발자에게 전송되지 않습니다.

다만 지도·검색·경로 기능을 쓰려면 휴대폰이 아래 4항의 공개 지도 서비스에 직접 요청을 보냅니다. 이 요청에는 좌표나 보고 있는 지도 영역이 담기고, 요청을 받는 서버는 접속한 IP 주소를 볼 수 있습니다.

1. 수집하지 않는 정보

DailyMap은 다음을 수집하지 않습니다. 여기서 '수집'은 개발자가 받아 보관하는 것을 말합니다.

  • 이름, 이메일, 전화번호 등 신원 정보 (가입 절차 자체가 없습니다)
  • 광고 식별자(IDFA/AAID), 기기 고유 식별자
  • 사용 통계·분석 데이터, 크래시 리포트
  • 위치 이력 (러닝 기록은 사용자가 기록을 시작했을 때만 기기 안에 저장되며 수집하지 않습니다)
  • 검색 이력 (최근 검색어는 기기 안에만 저장됩니다)

앱에는 광고 SDK, 분석 SDK, 크래시 수집 도구, 추적 도구가 포함되어 있지 않습니다.

3. 위치 정보

  • 사용 목적: 현재 위치 표시, 주변 장소 찾기, 경로·대중교통 경로의 출발지, 하차 알람, 러닝 기록
  • 먼저 안내합니다: 1.1.0부터 휴대폰의 위치 권한 창을 띄우기 전에, 위치를 무엇에 쓰고 어느 서비스로 좌표가 가는지 앱 안에서 먼저 안내합니다.
  • 기기 밖으로 나가는 경우: 개발자에게는 보내지 않습니다. 다만 주변 검색·경로 찾기 등을 할 때 좌표가 담긴 요청이 4항의 지도 서비스로 직접 전달됩니다.
  • 거부 시: 위치 권한 없이도 앱은 기본 위치 기준으로 동작하며, 검색으로 원하는 지역을 찾을 수 있습니다.
  • 화면이 꺼진 동안: 길안내(도보·자전거·자동차), 하차 알람, 러닝 기록 중에는 설정의 '화면이 꺼져도 위치 사용'(기본 켜짐)이 켜져 있으면 화면을 꺼도 위치를 계속 받습니다. iPhone은 화면 위쪽에 파란 위치 표시가, Android는 알림이 나타나며, 그 안내·알람·기록을 끝내면 즉시 멈춥니다. 이 설정을 끄면 앱을 보는 동안에만 동작합니다.
  • 하차 알람: 알람을 켠 동안 내릴 정류장까지 남은 거리를 기기 안에서 계산합니다.
  • 자동차 길안내: 회전 지점까지 남은 거리를 기기 안에서 계산하고, 주행 기록은 남기지 않습니다. 경로를 다시 찾을 때는 현재 위치가 경로 서비스(OSRM)로 다시 전송됩니다. iOS에서 '항상 허용'을 주지 않아도 안내는 동작합니다.
  • 러닝 기록 시 (1.1.0부터, iPhone만):
    • 사용자가 달리기를 시작한 뒤부터 끝낼 때까지만 위치를 받아 기록합니다.
    • '화면이 꺼져도 위치 사용'이 켜져 있으면 화면이 꺼져도 기록이 이어집니다(iPhone 상단 파란 표시).
    • 기록(GPS 궤적·시간·거리)은 기기에만 저장되며, 앱이 어디로도 전송하지 않습니다.
    • GPX 내보내기는 사용자가 시스템 공유 화면으로 직접 파일을 보낼 때만 일어납니다. 기본값으로 시작과 끝 지점 부근 200~400m(매번 무작위)를 잘라 내고 내보냅니다. 집 위치 등을 덜 드러내기 위한 처리이며, 완전한 익명화는 아닙니다.
    • Android에서는 1.1.0에 러닝 기능을 제공하지 않습니다.

4. 외부 서비스로 나가는 요청

지도와 장소·경로 정보를 보여 주려면 휴대폰이 아래 공개 서비스에 직접 요청을 보냅니다. 개발자가 중간에서 받거나 저장하는 서버는 없습니다. 요청에는 아래 표의 좌표·지도 영역·검색어가 담기며, 계정·광고 ID 같은 사용자 식별 정보는 넣지 않습니다. 다만 요청을 받는 서버는 접속한 IP 주소를 볼 수 있고, 각 서비스의 자체 정책에 따라 접속 기록을 남길 수 있습니다. 이는 개발자가 통제하지 않는 영역입니다.

1.1.0 이전 버전은 주변 장소 조회를 Overpass 서버 세 곳(maps.mail.ru 포함)에 동시에 보냈습니다. 1.1.0부터는 한 번에 한 서버에만 보내고, maps.mail.ru는 쓰지 않습니다.

5. 인공지능 기능

자연어 검색 해석·개인화 추천·요약은 전부 기기 안에서 동작합니다. Apple Intelligence 지원 기기에서는 iOS 내장 언어 모델을 추가로 쓸 수 있으며, 이 경우에도 문장이 기기를 벗어나지 않습니다. 외부 AI 서비스에는 어떤 데이터도 보내지 않습니다. 검색어 자체는 검색 결과를 받기 위해 4항의 장소 검색 서비스로 전달됩니다.

6. 아동 개인정보

DailyMap은 만 14세 미만 아동을 대상으로 하지 않으며, 연령과 무관하게 개발자가 개인정보를 수집하지 않습니다.

7. 이용자의 권리

개발자가 보관하는 개인정보는 없습니다. 기기에 저장된 데이터는 앱 안에서 직접 삭제할 수 있습니다.

  • 설정 → 저장 데이터 비우기: 즐겨찾기·최근 검색어·러닝 코스·러닝 기록 삭제
  • 설정 → 러닝 기록·코스 지우기: 러닝 코스와 기록만 삭제
  • 러닝 기록 화면에서 기록별 삭제
  • 앱 삭제: 모든 데이터 삭제

8. 방침 변경

방침이 바뀌면 앱 업데이트와 함께 이 문서를 갱신하고, 수집 항목이 늘어나는 변경은 앱 안에서 별도로 안내합니다.

Privacy Policy (English)

DailyMap has no accounts and no server of its own. We do not run any server that receives your coordinates — no relay, no cache. Favorites, recent searches, settings and run records are stored only on your device and are not sent to the developer. The app contains no ads, analytics, crash-reporting or tracking SDKs.

What leaves your phone. To show maps, places and routes, your phone sends requests directly to these public services. The requests contain coordinates, a map area or your search text, but no account or advertising ID; the receiving server can see your IP address and may keep logs under its own policy.

  • OpenStreetMap tiles (tile.openstreetmap.org, OpenStreetMap Foundation): the map area on screen.
  • Nominatim (nominatim.openstreetmap.org, OSMF): place search (search text and area; from 1.1.0 the area center is rounded to about 100 m) and the address of a point you select.
  • Overpass (overpass-api.de, and overpass.private.coffee only if that fails): nearby places (from 1.1.0 coordinates rounded to about 100 m, one server at a time) and running-course facts (points along the chosen course, once per course). Versions before 1.1.0 sent nearby queries to three servers at once, including maps.mail.ru; 1.1.0 no longer uses maps.mail.ru.
  • FOSSGIS routing (routing.openstreetmap.de, FOSSGIS e.V.): walking and cycling routes, and running-course generation (start point and generated waypoints).
  • OSRM demo server (router.project-osrm.org): car routes (origin and destination; during car navigation your current position is sent again when the route is recalculated).
  • Kakao Local API (dapi.kakao.com, Kakao Corp.): place search, nearby search and address lookup in Korea, called with the developer's API key (search and nearby coordinates rounded to about 100 m from 1.1.0).
  • ODsay (api.odsay.com): public transit routes in Korea (origin and destination; developer's API key).

Offline mode. From 1.1.0, offline mode stops all of the requests above, including map tiles; previously cached map images may still appear. In versions before 1.1.0, map tile requests continued in offline mode.

Location. Before the system location prompt, 1.1.0 shows an in-app notice explaining all of this; the app also works without location. Location is used to show your position, search nearby, find routes and transit, run the alight alarm and record runs. During turn-by-turn navigation (walking, cycling, driving), the alight alarm and run recording, location keeps updating with the screen off if "Use location with the screen off" is on (default on) — iPhone shows the blue indicator, Android shows a notification — and stops as soon as that journey ends.

Runs (iPhone, from 1.1.0). A run is recorded only after you start it and stops when you finish. Your GPS track, times and distance stay on the device and are never sent anywhere by the app. GPX export happens only when you share a file through the system share sheet; by default the first and last 200–400 m (random each time) are cut off, which is not full anonymization. Running is not available on Android in 1.1.0.

On-device only. AI features run entirely on-device. App data may be included in your own device backup (such as iCloud) but is never stored on developer servers. Delete it any time in Settings ("Clear saved data", or the running option that clears run records and courses), per run record, or by deleting the app.
