Demotape 개인정보처리방침 · 이용약관

최종 수정일: 2026년 9월 23일 · 운영자: INPHIL CHOI (CreativeLab) · 문의: creativelab.choi@gmail.com · Privacy Policy & Terms (English below)

요약 — Demotape 는 직접 만든 곡을 같은 Wi-Fi 의 옆 사람 폰으로 보내는 앱입니다. 회원가입이 없고, 개발자가 운영하는 서버가 없으며, 개인정보를 수집하지 않습니다. 곡·메모·설정은 이 기기에만 저장되고, 보낼 때만 두 기기 사이에서 암호화되어 직접 전달됩니다. 광고·분석·추적 SDK 가 없습니다.

1. 수집하는 개인정보

없습니다. 앱에는 회원가입·로그인이 없고, 이름·이메일·전화번호·위치·연락처를 묻지 않습니다. 분석·광고·추적 SDK 가 없고, 개발자가 운영하는 서버도 없습니다.

2. 기기에 저장되는 것

항목저장 위치삭제 방법
녹음하거나 가져온 곡 파일, 제목·장르·가사이 기기의 앱 저장소곡 화면에서 지우기, 또는 앱 삭제
구간 메모이 기기의 앱 저장소
보낼 때 보이는 이름(선택), 차단한 창작자 목록, 앱 설정이 기기의 앱 저장소
창작자 ID(서명 키) — 처음 실행할 때 기기에서 만듭니다. 개인 키는 기기 밖으로 나가지 않습니다.이 기기의 앱 저장소
창작자 팩 구매 여부(결제는 Apple 이 처리하며 개발자는 결제 정보를 받지 않습니다)이 기기의 앱 저장소

이 정보는 개발자나 제3자에게 전송되지 않으며, 서버 사본은 없습니다.

3. 다른 사람에게 전달되는 것

사용자가 곡을 직접 보낼 때만, 받는 사람의 기기로 곡 파일과 제목·보낸 사람 이름·장르·가사·길이, 창작자 ID(공개키 지문)와 서명, "직접 만든 곡" 확인 시각이 전달됩니다. "가까이 보내기" 화면이 열려 있는 동안에는 같은 Wi-Fi 의 기기에 보낸 사람 이름이 보이며, 화면을 닫으면 멈춥니다. 전송은 두 기기 사이에서 암호화(X25519 키 교환 + AES-256-GCM)되어 오가며 어떤 서버도 거치지 않습니다.

4. 권한

  • 마이크 — 곡을 녹음할 때만 사용합니다.
  • 로컬 네트워크 — 같은 Wi-Fi 의 기기와 곡을 주고받을 때만 사용합니다.

두 권한 모두 거부해도 앱의 나머지 기능은 그대로 쓸 수 있습니다.

5. 신고 처리

신고 기능은 사용자의 메일 앱에 개발자 주소로 보낼 메일 초안(곡 제목·창작자 ID·파일 해시)을 만듭니다. 사용자가 직접 보낼 때만 전송되며 곡 파일은 첨부되지 않습니다. 받은 신고는 확인·차단 목록 반영·회신 목적으로만 사용하고, 처리 후 1년 뒤 삭제합니다.

6. 아동

Demotape 는 만 14세 미만 아동을 포함해 누구의 개인정보도 수집하지 않습니다.

7. 변경

이 방침이 바뀌면 이 페이지와 앱 업데이트 안내로 알립니다.

이용약관

1. 직접 만든 곡만

Demotape 에는 본인이 직접 작사·작곡·연주·녹음해 권리를 가진 곡만 올릴 수 있습니다. 다른 사람의 음원, 권리자 허락 없는 커버·리믹스, 허락 없는 샘플이 들어간 곡은 올릴 수 없습니다. 곡을 추가할 때마다 이 내용을 확인하며, 확인 기록은 곡 카드에 서명과 함께 남습니다.

2. 불쾌한 콘텐츠 무관용

욕설·혐오·차별, 성적인 내용, 폭력·위협, 스팸이 담긴 곡이나 제목·가사는 허용하지 않습니다. 위반이 확인된 창작자 ID 는 신고 처리 목록에 올라 모든 사용자의 앱에서 받기·재생이 막힙니다.

3. 받은 곡의 권리

받은 곡의 권리는 만든 사람에게 있습니다. 창작자가 "다시 보내기 허용"을 켠 곡만 다른 사람에게 보낼 수 있고, 그 외의 복제·배포·상업적 이용은 할 수 없습니다.

4. 신고와 차단

받은 곡 화면에서 언제든 신고하거나 창작자를 차단할 수 있습니다. 신고한 곡은 즉시 이 기기에서 가려지고, 운영자는 신고를 24시간 안에 확인해 조치합니다. 문의: creativelab.choi@gmail.com

5. 서버가 없습니다

곡은 기기와 기기 사이에서만 오가며 운영자는 곡 파일·가입 정보를 보관하지 않습니다. 앱을 지우면 기기에 저장된 곡도 함께 지워지니 중요한 곡은 따로 보관하세요.

6. 권리자 신고

본인의 저작물이 권리 없이 Demotape 로 전달되고 있다면 creativelab.choi@gmail.com 으로 (1) 권리자 정보 (2) 대상 곡 제목·창작자 ID 또는 파일 해시 (3) 권리 근거를 보내 주세요. 확인되면 해당 창작자 ID·음원 해시를 신고 처리 목록에 추가해 앱 업데이트로 배포합니다.

7. 앱 내 구입

창작자 팩(한 번 결제, 자동 갱신 없음)과 개발자 응원에는 Apple 표준 이용약관(EULA)이 함께 적용됩니다.
