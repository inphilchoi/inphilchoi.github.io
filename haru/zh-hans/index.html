连接方式

两种方式，
任你选择。

安装时选择，之后随时可以用 haru-pc relay on · off 切换。

Haru 中继 推荐

  • 无需任何设置，在家在外都能连接
  • 端到端加密 — 中继看不到内容，只保存访问令牌的哈希值
  • 关掉应用，交代的事也会继续；重新打开时会弹出审批卡片
  • 由 CreativeLab 运营（Cloudflare）

自托管直连

  • 不使用我们的中继 — 手机直接连接你的电脑
  • 在同一 Wi-Fi 下直接连接，在外面则通过你自己的 Tailscale 或你自己运营的中继
  • 审批卡片在应用打开时接收
  • 如何运营自己的中继

安装

一行命令
就能装好。

打开终端（Windows 为 PowerShell），粘贴下面这一行。5~10 分钟即可完成。

curl -fsSL https://raw.githubusercontent.com/inphilchoi/haru-pc/main/install.sh | bash

Mac 请在终端应用（应用程序 ▸ 实用工具）中运行。Linux 如果有 systemd，开机时会自动启动。

irm https://raw.githubusercontent.com/inphilchoi/haru-pc/main/install.ps1 | iex

从开始菜单打开 PowerShell 并粘贴。支持 Windows 10、11。

  1. 安装所需组件

    Node.js（没有或版本过旧时会重新安装或更新）、经过验证版本的 OpenClaw，以及 Haru PC 安全插件。

  2. 安全地完成设置

    所有改动都需手机审批，使用加密连接（TLS），只允许在同一 Wi-Fi 内直接访问。

  3. 选择连接方式

    1) Haru 中继（推荐）2) 自托管直连。以后可以更改。

  4. 选择 AI

    登录 ChatGPT、Claude、Gemini 等公开 AI 或使用 API 密钥，也可以用免费本地模型。登录在各公司的官方页面上亲自完成。

  5. 显示连接二维码

    在后台保持运行，并显示供手机扫描的二维码。

如果想先看看脚本内容：install.sh · install.ps1

选择 AI

一直在用的公开 AI，
照样用。

Haru PC 不会询问你的密码。登录在各公司的页面上完成，Haru PC 只获取所需的权限。随时可以更换。

命令连接的对象
haru-pc model login chatgpt用 ChatGPT 订阅方案登录（OpenAI 页面）

haru-pc model local自己电脑上的免费本地模型 — 私密但较慢。建议 RAM 16GB 以上

推荐配置 — 一直开着的 Mac mini。耗电少，无需显示器也能运行；RAM 16GB 以上的话，还能用免费本地模型。

关掉应用也行

  1. 说出来

    “在我的电脑上，在文档文件夹里建一个 备忘.txt，写上 你好”

  2. 交给电脑

    点 [交给电脑]，就会发送到电脑。

  3. 审批

    电脑在做改动前会发来卡片 — “写入文件 · 目标 · 内容”。没问题就点 [执行]，否则点 [取消]。

  4. 结果

    完成后会用“电脑：……”告诉你。

在电脑上使用的命令

命令作用
haru-pc pair显示手机连接二维码（10 分钟，仅一次）
haru-pc status是否在运行、已连接的手机
haru-pc allow <文件夹>添加 Haru PC 可以操作的文件夹（默认：文档、下载、桌面）
haru-pc relay on | off切换连接方式 — Haru 中继 / 自托管直连
haru-pc relay url <wss://…>使用自己运营的中继（用 default 恢复默认）
haru-pc remote on直连模式下在外面也能用 — 通过你自己的 Tailscale
haru-pc readonly on只查看，不做任何改动
haru-pc model查看、更换当前 AI 模型
haru-pc unpair删除已连接的手机
haru-pc update更新到经过验证的下一个版本
haru-pc uninstall停止并删除

安全

没有你的允许，
什么都不会改变。

每次改动都要审批

写入、移动文件和执行命令，都要在手机上逐条审批。没有“始终允许”。10 分钟内未回复即视为拒绝。

只在允许的文件夹内

默认是文档、下载、桌面。其他位置一律禁止。不会删除，而是移到“整理箱”。

命令一次只执行一条

管道、串联、重定向这类可能让卡片上显示的内容与实际运行的内容不一致的命令，会被拦截。

AI 改不了设置

允许的文件夹、只读等安全设置，只能由人在电脑上更改。

不付款、不登录

不会转账或购物，也不会输入密码。

中继看不到内容

使用只有手机和电脑知道的密钥进行端到端加密。中继只保存房间号和访问令牌的哈希值。不想用中继的话，可以选择自托管直连。

常见问题

你可能想问。

Haru 应用在哪里下载？

正在准备在 iPhone（App Store）和 Android（Google Play）上架。上架后会第一时间在本页公布。

Haru PC 免费吗？

是的，免费且开源。如果连接 ChatGPT、Claude 等外部 AI，则适用该公司的订阅方案和使用限额。本地模型不产生费用。

不支持 Apple Intelligence 的手机也能用吗？

能。可以用基于规则运行的助理模式代替 AI 对话，使用日程、记账、Haru PC 等全部功能。AI 对话需要 iPhone 15 Pro 及以上机型。

收不到审批卡片。

请打开 Haru 应用看看。如果交代的事正在进行，等待中的卡片会弹出来。请在电脑上用 haru-pc status 确认 Haru PC 是否在运行。较小的本地模型给出第一个回答可能需要几分钟。

因为在允许的文件夹之外被拦截了。

在电脑上运行 haru-pc allow ~/想要的文件夹，就能在那个文件夹里操作。AI 无法自行更改这项设置。

我不想使用 Haru 中继服务器。

安装时选择“自托管直连”，或运行 haru-pc relay off。在同一 Wi-Fi 下手机会直接连接电脑；在外面则可以用你自己的 Tailscale（haru-pc remote on）或你自己运营的中继（haru-pc relay url wss://…）。切换后请用 haru-pc pair 重新连接。

Haru PC 用的是什么 AI？

使用你选择的公开 AI（ChatGPT、Claude、Gemini 等）或你电脑上的本地模型。手机上的 Haru 应用使用设备上的 Apple Intelligence，Haru PC 使用连接到电脑的 AI，两者相互独立。

安装会对我的电脑做哪些改动？

如果没有 Node.js 或版本过旧，会进行安装或更新（Mac 通过 Homebrew），把 OpenClaw 和 Haru PC 安装到 ~/.haru-pc，并注册为后台服务。可以用 haru-pc uninstall 停止并删除。

我的数据会去哪里？

手机上的对话和记录只保存在手机上，交代的事只在手机和你的电脑之间传输。详情请参阅隐私政策。
