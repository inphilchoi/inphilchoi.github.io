원하는 AI로

ChatGPT·Claude 구독 로그인, API 키, 또는 내 컴퓨터의 무료 로컬 모델.

오픈소스

오픈소스 AI 비서 OpenClaw 위에서 동작하고, 소스는 GitHub에 공개돼 있어요.

설치

명령 한 줄이면
설치돼요.

터미널(Windows는 PowerShell)을 열고 아래 한 줄을 붙여 넣으세요. 5~10분이면 끝나요.

curl -fsSL https://raw.githubusercontent.com/inphilchoi/haru-pc/main/install.sh | bash

Mac은 터미널 앱(응용 프로그램 ▸ 유틸리티)에서 실행해요. Linux는 systemd가 있으면 켜질 때 자동으로 시작돼요.

irm https://raw.githubusercontent.com/inphilchoi/haru-pc/main/install.ps1 | iex

시작 메뉴에서 PowerShell을 열고 붙여 넣어요. Windows 10·11을 지원해요.

  1. 필요한 것을 설치해요

    Node.js(없거나 오래됐으면 새로 설치·업데이트)와 검증한 버전의 OpenClaw, 하루 PC 안전 플러그인.

  2. 안전하게 설정해요

    바꾸는 일은 모두 폰 승인, 암호화 연결(TLS), 같은 Wi-Fi 안에서만 직접 접속.

  3. AI를 골라요

    ChatGPT·Claude 로그인, API 키, 무료 로컬 모델 중 하나. 로그인은 각 회사의 공식 페이지에서 직접 해요.

  4. 연결 QR이 떠요

    백그라운드에서 켜 두고, 폰으로 찍을 QR을 보여 줘요.

스크립트를 먼저 읽어 보고 싶다면 install.sh · install.ps1

AI 고르기

쓰던 AI를
그대로.

하루 PC는 비밀번호를 묻지 않아요. 로그인은 각 회사 페이지에서 하고, 하루 PC는 필요한 권한만 받아요. 언제든 바꿀 수 있어요.

명령연결되는 것
haru-pc model login chatgptChatGPT 요금제로 로그인 (OpenAI 페이지)
haru-pc model login claudeClaude 요금제 (먼저 claude auth login)
haru-pc model login copilotGitHub Copilot
haru-pc model key openaiAPI 키 (openai·anthropic·gemini·mistral·deepseek 등)
haru-pc model local내 컴퓨터의 무료 로컬 모델 — 비공개지만 느려요. RAM 16GB 이상 권장

추천 구성 — 늘 켜 두는 Mac mini. 전기를 적게 쓰고 모니터 없이 돌아가며, RAM 16GB 이상이면 무료 로컬 모델까지 쓸 수 있어요.

앱을 닫아도 돼요

맡긴 뒤 앱을 닫아도 PC는 15분까지 일을 이어 가요. 다시 열면 기다리던 승인 카드가 떠요.

  1. 말하기

    "내 PC에서 문서 폴더에 메모.txt 만들고 안녕 이라고 써 줘"

  2. PC에 맡기기

    [PC에 맡기기]를 누르면 PC로 보내요.

  3. 승인

    PC가 바꾸기 전에 카드를 보내요 — "파일 쓰기 · 대상 · 내용". 맞으면 [실행], 아니면 [취소].

  4. 결과

    끝나면 "PC: …"로 알려 줘요.

안전

허락하지 않으면
아무것도 바뀌지 않아요.

바꿀 때마다 승인

파일 쓰기·옮기기, 명령 실행은 한 건씩 폰에서 승인해요. "항상 허용"은 없어요. 10분 안에 답하지 않으면 거부돼요.

허용한 폴더 안에서만

기본은 문서·다운로드·바탕화면. 그 밖은 막혀요. 지우지 않고 '정리함'으로 옮겨요.

명령은 한 번에 하나

파이프·연결·리디렉션처럼 카드에 보이는 것과 실제로 도는 것이 달라질 수 있는 명령은 막아요.

AI는 설정을 못 바꿔요

허용 폴더·읽기 전용 같은 안전 설정은 사람이 컴퓨터에서만 바꿀 수 있어요.

결제·로그인 안 해요

돈을 보내거나 사거나, 비밀번호를 입력하지 않아요.

중계는 내용을 못 봐요

폰과 PC만 아는 키로 종단간 암호화. 중계는 방 번호와 접속 토큰의 해시만 저장해요.

자주 묻는 질문

궁금한 것.

하루 앱은 어디서 받나요?

iPhone(App Store)·Android(Google Play) 출시를 준비하고 있어요. 나오면 이 페이지에 바로 알릴게요.

하루 PC는 무료인가요?

네, 무료이고 오픈소스예요. ChatGPT·Claude 같은 외부 AI를 연결하면 그 회사의 요금제·사용 한도가 적용돼요. 로컬 모델은 비용이 없어요.

Apple Intelligence가 안 되는 폰도 쓸 수 있나요?

네. AI 대화 대신 규칙으로 동작하는 비서 모드로 일정·가계부·하루 PC 등 모든 기능을 쓸 수 있어요. AI 대화는 iPhone 15 Pro 이상에서 돼요.

승인 카드가 오지 않아요.

하루 앱을 열어 보세요. 맡긴 일이 진행 중이면 기다리던 카드가 떠요. 컴퓨터에서 haru-pc status로 하루 PC가 켜져 있는지 확인해 주세요. 작은 로컬 모델은 첫 답이 몇 분 걸릴 수 있어요.

허용한 폴더 밖이라 막혔어요.

컴퓨터에서 haru-pc allow ~/원하는폴더를 실행하면 그 폴더에서도 일할 수 있어요. AI는 이 설정을 스스로 바꿀 수 없어요.

설치가 내 컴퓨터에 무엇을 바꾸나요?

Node.js가 없거나 오래됐으면 설치·업데이트하고(Mac은 Homebrew), OpenClaw와 하루 PC를 설치해 ~/.haru-pc에 두고, 백그라운드 서비스로 등록해요. haru-pc uninstall로 멈추고 지울 수 있어요.

내 데이터는 어디로 가나요?

폰의 대화·기록은 폰에만, 맡긴 일은 폰과 내 PC 사이에서만 오가요. 자세한 내용은 개인정보처리방침을 보세요.
